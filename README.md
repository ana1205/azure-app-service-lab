
# Práctica 12: Azure Portal - App Service

## Información general

**Asignatura:** Laboratorio de Azure  
**Práctica:** Azure Portal - App Service  
**Objetivo:** Publicar una aplicación web mediante Azure App Service y comprobar su funcionamiento.

## Objetivos específicos

- Preparar una aplicación web para su publicación.
- Configurar un recurso de Azure App Service.
- Desplegar la aplicación en la nube.
- Verificar el acceso a la aplicación publicada.
- Documentar el procedimiento y los resultados obtenidos.

## Estructura del repositorio

- `app/`: código fuente de la aplicación web.
- `evidencias/`: capturas de pantalla del procedimiento.
- `reporte/`: reporte de evidencias en formato Word.

## Tecnologías
